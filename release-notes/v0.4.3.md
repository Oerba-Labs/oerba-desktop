Oerba Desktop 0.4.3: Expo apps load in the iOS Simulator.

- **Open in iOS Simulator now loads the app.** In 0.4.2 Expo Go was told to fetch the app's code from an `https://` address on this Mac, where the forward speaks plain `http`, and showed "Could not connect to development server". The forward now tells the workspace's dev server the address the request really came from, and Expo builds the app's addresses from it.
- **Nothing to set in the workspace.** `npx expo start` is enough; the `EXPO_PACKAGER_PROXY_URL` that 0.4.2 asked for is no longer needed. The project needs Expo SDK 58 or later, the first that reads that address.

If you have an earlier version, the menu bar item offers this one: **Update to 0.4.3…**, then **Download**, then **Restart now**.
