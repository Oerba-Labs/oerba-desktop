Oerba Desktop 0.4.2: open an Expo app in the iOS Simulator.

- **Open in iOS Simulator.** A workspace's Metro port (8081 or 19000) in the menu bar and the Dock now offers **Open in iOS Simulator**. It forwards the port to this Mac, boots an iPhone simulator if none is running, shows it (in Device Hub on Xcode 27, in Simulator before it), and has Expo Go load the workspace's app, so an edit in the workspace reloads the phone. It needs Xcode, and Expo Go in the simulator; if either is missing it says what to install, and installs nothing itself.
- **Start Expo with the forward's address.** In the workspace, run `EXPO_PACKAGER_PROXY_URL=http://127.0.0.1:8081 npx expo start` (with the number the app shows), so the phone asks for the app's code through the forward.
- **Updates are checked against their sum.** A new test, run before every release, proves that an update whose checksum differs from the release's is refused and never offered for install.

If you have an earlier version, the menu bar item offers this one: **Update to 0.4.2…**, then **Download**, then **Restart now**.
