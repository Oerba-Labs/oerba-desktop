Oerba Desktop 0.5.1: the panel alone.

- **Device Hub stays closed.** Open in iOS Simulator showed the phone in the panel and, behind it, in Device Hub too: serve-sim, the panel's helper, opened Device Hub each time it started. Oerba's copy of it no longer does. **Pop out** still shows the phone in Device Hub when you want it there.
- **The panel starts when port 3200 is taken.** The panel's helper was told to use port 3200 alone, so it could not start while anything else held that port, such as a workspace's port 3200 forwarded to this Mac. It now takes the first free port from 3200.

If you have an earlier version, the menu bar item offers this one: **Update to 0.5.1…**, then **Download**, then **Restart now**.
