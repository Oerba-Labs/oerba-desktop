Oerba Desktop 0.4.0.

A workspace's dev server now opens on this Mac's `localhost`. In the menu bar item, under each of your started workspaces, pick **Open on localhost:8081** (or another common port): the app listens on `127.0.0.1` and `::1`, on the same number where it is free and the next free one where it is not, and relays HTTP and websockets to that port of the workspace. Metro, Expo and a web dev server work from the Simulator and the browser as if they ran on the Mac. A running forward shows as **localhost:8081 → 8081 (stop)**; it stops with its workspace, when you stop it, and when the app quits.

Only the app's own browser-facing checks stand between a web page and a forward: a page of another site cannot read from or write through one. `SECURITY.md` says what the relay refuses and why. Nothing else changes: the app still holds no secret and deploys nothing.

If you have 0.3.1, the app offers this one from its menu bar item: **Update to 0.4.0…**, then **Download**, then **Restart now**.
