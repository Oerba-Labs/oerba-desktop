Oerba Desktop 0.6.3: it asks before a workspace's code first runs on your Mac.

- **Asked once for each workspace.** An app in the iOS Simulator runs on your Mac, as you, and a test on 28 Nov showed that a workspace's code there can read your files. So before a workspace's app first opens in the simulator, the app asks: *Run demo's code on this Mac?* Open, or Not Now, which starts nothing. Your yes is remembered for that workspace. **Forget Workspaces Allowed in Simulator**, in the menu bar item, lets every yes go, closes the panel and quits Expo Go, and each workspace is asked again. Open only workspaces whose code you would run on this Mac yourself.
- **Dev Panel opens the app into an empty panel.** With the panel open and no app in it, pressing Dev Panel in a room whose Metro is running now opens that workspace's app there, rather than closing the panel.

Oerba 0.6.2 finds this update by itself within the hour, or when your Mac wakes, and the menu bar item offers **Restart to Update to 0.6.3**.
